Infrastructure Capacity Certificate

The Infrastructure Capacity Certificate (ICC) is an interactive assessment per development that evaluates current capacity against required capacity across multiple domains and produces a simple traffic-light result and recommendations.

Example: Development assessment (prototype)

Location: Leeds West

Proposed homes: 3,200

Development status

Not infrastructure-ready

Required investments

  • Grid reinforcement
  • Fibre extension
  • Healthcare capacity expansion

How it should work (notes)

  • Each development links to live capacity datasets (utilities, schools, health, transport).
  • The ICC should produce a small public certificate that is linked from planning applications and project pages.
  • Certificates should be versioned so they record the date of assessment and the data sources used.
  • Where deficits exist, the certificate should list mitigation actions and responsible delivery programmes.
